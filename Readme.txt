# 🎬 Netflix Data Analysis Dashboard

An interactive web-based app built with **Streamlit** to perform comprehensive statistical analysis on Netflix titles dataset. The app includes graphical visualizations, descriptive statistics, probability analysis, and regression modeling.

---

## 📊 Features

- Graphical and tabular data representation
- Descriptive statistics and confidence intervals
- Probability distribution analysis
- Linear regression modeling
- Clean, user-friendly Streamlit interface

---

## 🧰 Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Seaborn
- Matplotlib
- SciPy
- Scikit-learn
